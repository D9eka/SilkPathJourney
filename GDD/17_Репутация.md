# Репутация

## Обзор

Репутация отражает известность и отношение торгового мира к игроку. Это глобальный параметр (единый для всего мира, не региональный), который меняется от поступков игрока.

Репутация — параметр, а не навык (09_Навыки.md). Навыки растут от обучения, репутация — от решений.

Диапазон: 0–100. Стартовое значение: 25 (зависит от предыстории).

## Пороги и статусы

| Диапазон | Статус | Эффекты |
|----------|--------|---------|
| 0–9 | Изгой | +30% цены покупки, некоторые пограничные города не пускают, бандиты нападают на 20% чаще |
| 10–24 | Неизвестный | +10% цены покупки, слухи в тавернах неполные |
| 25–49 | Торговец | Базовые цены, полный доступ ко всем городам и зданиям |
| 50–74 | Уважаемый | −20% пошлины, подробные слухи, доступ к заданиям гильдии |
| 75–89 | Известный | −50% пошлины, уникальные варианты в событиях, лучшие спутники |
| 90–100 | Легенда | Лучшие цены (−5% покупка), уникальные задания, NPC сами предлагают выгодные сделки |

Пороги 50+ и 80+ из 08_Экономика.md (скидка на пошлины) соответствуют статусам «Уважаемый» и «Известный».

## Источники изменения

### Положительные

| Действие | Изменение | Примечание |
|----------|-----------|------------|
| Выполнить задание основной ветки | +10..+15 | Зависит от номера задания |
| Выполнить побочное задание | +5..+10 | |
| Помочь путнику на дороге | +3..+5 | Событие «Путник на дороге» |
| Спасти караван (событие) | +5..+8 | |
| Крупная успешная сделка (100+ монет) | +2 | Не чаще 1 раза за 5 дней |
| Пожертвование в храме | +3 | |
| Защитить караван-сарай (событие) | +5 | |

### Отрицательные

| Действие | Изменение | Примечание |
|----------|-----------|------------|
| Отказать в помощи путнику | −3..−5 | |

## Затухание

Репутация медленно стремится к нейтральному значению 25:

- При репутации > 25: −1 каждые 10 дней
- При репутации < 25: +1 каждые 10 дней

Мир забывает. Чтобы поддерживать высокую репутацию, нужно продолжать совершать хорошие поступки.

Затухание не действует первые 5 дней после изменения репутации.

## Влияние на системы

### Торговля (08_Экономика.md)

Репутация влияет на цены через модификатор по порогам:
- Изгой: +30% к ценам покупки
- Неизвестный: +10% к ценам покупки
- Уважаемый и выше: стандартные цены или лучше

### Пошлины (08_Экономика.md)

- Репутация 50+: −20% пошлина
- Репутация 75+: −50% пошлина
- Изгой (< 10): +20% пошлина

### События (06_События.md)

Репутация используется как условие:

```
conditions:
  - type: MinReputation, value: 50   // Доступно только Уважаемым+
  - type: MaxReputation, value: 24   // Доступно только Неизвестным и ниже
```

Некоторые варианты выбора требуют определённой репутации:
- «Воспользоваться авторитетом» — MinReputation 50
- «Пригрозить от имени гильдии» — MinReputation 75

### Задания (07_Задания.md)

- Задание 5 «Империя торговли» (фирман): требует MinReputation 50
- Побочные задания гильдии: доступны при MinReputation 50
- Некоторые NPC отказываются говорить при репутации < 25

### Спутники (11_Спутники.md)

- Базовые спутники: доступны всем
- Опытные спутники: требуют MinReputation 50
- Уникальные спутники из заданий: без ограничений

### Города

- При репутации < 10: пограничные города могут отказать во въезде (50% шанс)
- При репутации < 5: даже обычные города могут отказать (25% шанс)
- Столицы и торговые узлы не отказывают (слишком крупные для контроля)

## Отображение

Репутация не показывается в HUD (как и деньги). Видна:
- В экране «Торговец» (09_Навыки.md) — текущее значение и статус
- В тултипе при наведении на информацию о ценах — как фактор
- В событиях — когда является условием для варианта

## Структура данных

```
ReputationData:
  value: int                         // Текущая репутация (0-100)
  lastChangeDay: int                 // День последнего изменения
  status: ReputationStatus           // Текущий статус

ReputationStatus:
  - Outcast          // Изгой (0-9)
  - Unknown          // Неизвестный (10-24)
  - Trader           // Торговец (25-49)
  - Respected        // Уважаемый (50-74)
  - Famous           // Известный (75-89)
  - Legend            // Легенда (90-100)
```
