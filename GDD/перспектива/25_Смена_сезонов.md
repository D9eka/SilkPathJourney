# Смена сезонов

> **Перспективный дизайн.** Этот документ описывает систему смены сезонов, которая НЕ запланирована к немедленной реализации. Система расширяет существующие механики дорог, событий и экономики, добавляя временное измерение к путешествию. Документ создан для фиксации идей и обеспечения совместимости с текущей архитектурой.

## Обзор

Сезоны меняются динамически в течение забега. Один забег длится несколько месяцев игрового времени (типичное прохождение — 150-250 дней), поэтому игрок застанет 1-3 смены сезонов. Сезон влияет на:

- Доступность горных перевалов (зимой закрываются)
- Дорожные эффекты (биом + сезон = конкретная погода)
- Цены на продовольствие и сырьё (урожай, дефицит)
- Расход припасов (зима — больше, лето — жара)
- Пул событий (сезонные события и фестивали)
- Скорость порчи товаров (жара ускоряет)

Сезон — глобальный параметр: он одинаков для всей карты. Климатические различия уже учтены через биомы (смотри Дороги).

## Календарь

### Четыре сезона

| Сезон | Дни | Описание |
|-------|-----|----------|
| Весна (春) | 1-90 | Таяние снегов, паводки, цветение. Перевалы начинают открываться |
| Лето (夏) | 91-180 | Жара в пустынях, муссоны на побережье. Все маршруты открыты |
| Осень (秋) | 181-270 | Урожай, идеальные условия для путешествий. Лучший торговый сезон |
| Зима (冬) | 271-360 | Снег, холод. Горные перевалы закрываются. Пустыня комфортна |

Год = 360 дней. После дня 360 — снова день 1 (новый год).

### Стартовый сезон

Игрок выбирает стартовый месяц на экране создания забега (после выбора телеги и эпохи). Для простоты — выбор сезона:

| Старт | Стратегия |
|-------|-----------|
| Весна | Классический. Выезд из Чанъаня весной → прибытие на запад осенью. Рекомендуется новичкам |
| Лето | Быстрый старт, но жара на пустынных участках |
| Осень | Дешёвая еда, но зима застанет в пути |
| Зима | Хардкор. Горные маршруты недоступны сразу |

По умолчанию — Весна.

## Влияние на дороги

Сезон модифицирует существующие дорожные эффекты (смотри Дороги). Каждый биом реагирует на сезон по-своему.

### Сезонные модификаторы дорожных эффектов

Множитель применяется к базовой вероятности эффекта (из матрицы биом × эффект, смотри Дороги):

| Биом | Весна | Лето | Осень | Зима |
|------|-------|------|-------|------|
| Равнина | Грязь ×2.0 | Жара ×1.5 | ×1.0 (идеально) | Дождь ×1.5 |
| Пустыня | Солнце ×1.3 | Жара ×2.0, Буря ×1.5 | Солнце ×1.2 | ×0.5 (прохладно) |
| Горы | Грязь ×1.5 | ×1.0 | ×1.0 | **Блок** или Буря ×2.0 |
| Лес | Грязь ×1.5 | ×1.0 | Туман ×1.5 | Дождь ×1.3 |
| Побережье | Дождь ×1.5 | Буря ×1.5 (муссон) | ×1.0 | Дождь ×1.3 |
| Речная долина | Грязь ×2.0 (паводок) | ×1.0 | ×1.0 | Туман ×1.5 |
| Высокогорье | Грязь ×1.5 | ×1.0 | Буря ×1.3 | **Блок** |

**Блок** = маршрут недоступен в этот сезон. Игрок не может выбрать заблокированный маршрут. На карте он отображается серым с иконкой снежинки.

### Заблокированные маршруты зимой

| Сегмент | Биом | Причина |
|---------|------|---------|
| Кашгар — Хотан | Высокогорье | Заснеженные перевалы Куньлунь |
| Лхаса — Лицзян | Горы | Тибетское нагорье |
| Лхаса — Хотан | Высокогорье | Перевал Каракорум |
| Балх — Кабул | Горы | Перевалы Гиндукуша |
| Кабул — Таксила | Горы | Хайберский проход (частично) |
| Табриз — Трабзон | Горы | Понтийские горы |

Блокировка снимается в первый день Весны. Есть шанс (20%), что перевал откроется на 5-10 дней раньше (событие «Ранняя оттепель»).

### Формула с сезонным модификатором

Существующая формула (смотри Дороги) расширяется:

```
шанс_эффекта = базовый_шанс × биом_множитель × сезон_множитель
```

Пример: Дождь в Речной долине весной = 0.20 × 1.0 × 2.0 = 0.40 (40% вместо 20%).

## Влияние на экономику

Сезон добавляет множитель `seasonPriceMod` к формуле цены (смотри Экономика):

```
price = base_price × buy_coef × seasonPriceMod
```

### Сезонные ценовые множители

| Категория | Весна | Лето | Осень | Зима |
|-----------|-------|------|-------|------|
| Food | ×1.1 (запасы тают) | ×1.0 | ×0.8 (урожай!) | ×1.3 (дефицит) |
| Raw | ×1.0 | ×1.0 | ×0.9 (сезон сбора) | ×1.1 |
| Craft | ×1.0 | ×1.0 | ×1.0 | ×1.0 |
| Luxury | ×0.9 (шёлковый сезон) | ×1.0 | ×1.1 (предзимний спрос) | ×1.2 (подарки) |
| Exotic | ×1.0 | ×1.0 | ×1.0 | ×1.0 |
| Animals | ×1.1 (молодняк) | ×1.0 | ×0.9 (после выпаса) | ×1.2 (корм дорогой) |

### Сезонный расход припасов

Зимой расход припасов увеличивается (нужно топливо и тёплая пища):

| Сезон | Множитель расхода |
|-------|-------------------|
| Весна | ×1.0 |
| Лето | ×1.1 (жара → больше воды, только в пустыне/высокогорье) |
| Осень | ×1.0 |
| Зима | ×1.2 (отопление, горячая пища) |

Множитель применяется к суточному расходу (смотри Привал и кризисы).

### Скорость порчи товаров

Жара ускоряет порчу, холод замедляет:

| Сезон | Множитель срока хранения |
|-------|--------------------------|
| Весна | ×1.0 |
| Лето | ×0.7 (порча быстрее: Food 10→7 дней, Raw 30→21 день) |
| Осень | ×1.0 |
| Зима | ×1.5 (порча медленнее: Food 10→15 дней, Raw 30→45 дней) |

## Влияние на события

### Сезонный множитель в формуле шанса

Существующая формула (смотри События):

```
finalChance = baseChance × dangerMod × biomeMod × weatherMod × upgradeMod × cityModMod
```

Расширяется:

```
finalChance = baseChance × dangerMod × biomeMod × weatherMod × seasonMod × upgradeMod × cityModMod
```

`seasonMod` зависит от тега события:

| Тег события | Весна | Лето | Осень | Зима |
|-------------|-------|------|-------|------|
| heat (жара) | ×0.5 | ×1.5 | ×0.8 | ×0.0 |
| cold (холод) | ×0.8 | ×0.0 | ×0.5 | ×1.5 |
| flood (наводнение) | ×2.0 | ×0.5 | ×0.3 | ×0.0 |
| bandit (разбойники) | ×1.0 | ×1.2 | ×1.0 | ×0.7 |
| disease (болезнь) | ×1.0 | ×1.3 | ×0.8 | ×0.7 |
| festival (фестиваль) | ×1.0 | ×0.5 | ×1.5 | ×0.5 |
| без тега | ×1.0 | ×1.0 | ×1.0 | ×1.0 |

### Сезонные события

Новые события, доступные только в определённый сезон:

### Сезонные фестивали в городах

Города проводят фестивали в определённые сезоны. Фестиваль — это городское событие, доступное при посещении города в нужный сезон:

| Фестиваль | Сезон | Города | Эффект |
|-----------|-------|--------|--------|
| Новруз (Навруз) | Весна (день 1-10) | Самарканд, Бухара, Мешхед, Рей, Табриз | +10 мораль, скидка 10% на все товары |
| Праздник середины осени (中秋節) | Осень (день 195-200) | Пекин, Чанъань, Ханчжоу, Цюаньчжоу | +5 мораль, Luxury −15% |
| Рамадан | Лето (день 120-150) | Багдад, Дамаск, Каир, Мекка, Медина | Торговля только утром и вечером, +15 репутация при уважении |
| Зимняя ярмарка | Зима (день 300-320) | Константинополь, Трабзон, Антиохия | Все товары доступны, +5 мораль |
| Дивали | Осень (день 250-255) | Дели, Камбей, Таксила | +10 мораль, Exotic −20%, фейерверки |

## Структура данных

### SeasonType (enum)

```
SeasonType:
  Spring = 0   // Весна (春)
  Summer = 1   // Лето (夏)
  Autumn = 2   // Осень (秋)
  Winter = 3   // Зима (冬)
```

### SeasonConfig (ScriptableObject)

```
SeasonConfig:
  seasonType: SeasonType
  displayName: LocalizedString     // "Весна", "春"
  startDay: int                    // 1, 91, 181, 271
  endDay: int                      // 90, 180, 270, 360
  supplyMultiplier: float          // 1.0, 1.1, 1.0, 1.2
  spoilageMultiplier: float        // 1.0, 0.7, 1.0, 1.5
  priceMods: SeasonPriceMod[]      // По одному на категорию товаров
  effectMods: SeasonEffectMod[]    // По одному на пару (биом, эффект)
  eventTags: SeasonEventTag[]      // Множители для тегов событий
  blockedBiomes: BiomeType[]       // Какие биомы заблокированы (горы зимой)
```

### SeasonPriceMod

```
SeasonPriceMod:
  category: GoodCategory           // Food, Raw, Craft, Luxury, Exotic, Animals
  priceMultiplier: float           // 0.8 — 1.3
```

### SeasonEventTag

```
SeasonEventTag:
  tag: string                      // "heat", "cold", "flood", "bandit", "disease", "festival"
  chanceMod: float                 // Множитель шанса для событий с этим тегом
```

### SeasonFestival

```
SeasonFestival:
  id: string                       // "nowruz", "mid_autumn", etc.
  displayName: LocalizedString
  season: SeasonType
  dayStart: int                    // День начала (внутри сезона)
  dayEnd: int                      // День конца
  cities: CityId[]                 // Где проводится
  moraleBonus: int                 // Бонус морали при посещении
  priceDiscount: float             // Скидка на товары (0.1 = 10%)
  reputationBonus: int             // Бонус репутации
  specialEffect: string            // Описание особого эффекта
```

### Приоритет реализации

1. Базовый календарь + HUD (счётчик сезонов)
2. Блокировка горных маршрутов зимой
3. Сезонные ценовые множители
4. Сезонные модификаторы дорожных эффектов
5. Сезонные события (12 штук)
6. Городские фестивали (5 штук)
7. Скорость порчи товаров
