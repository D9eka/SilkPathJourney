# Мини-игры

> **Перспективный дизайн.** Этот документ описывает систему мини-игр, которая НЕ запланирована к немедленной реализации. Мини-игры добавляют интерактивность в городские сцены и углубляют ролевой аспект торговли. Документ создан для фиксации идей и обеспечения совместимости с текущей архитектурой.

## Обзор

Две мини-игры дополняют основной геймплей: **Торг** (хагглинг на базаре) и **Нарды** (в таверне). Обе мини-игры опциональны — игрок всегда может торговать и посещать таверну без них. Мини-игра длится 30-60 секунд и не ломает темп забега.

Мини-игры привязаны к конкретным зданиям:

| Мини-игра | Здание | Доступность |
|-----------|--------|-------------|
| Торг | Рынок | При покупке/продаже товара на сумму ≥ 50 монет |
| Нарды | Таверна | Всегда при посещении таверны |

## Мини-игра 1: Торг (Haggling)

### Концепция

Торг на базаре — центральная механика Шёлкового пути. Вместо мгновенной покупки по фиксированной цене игрок может попытаться сбить цену (или поднять при продаже) через серию раундов переговоров. Успех зависит от навыка Торговля, знания языка и репутации.

### Когда доступен

- Покупка или продажа товара стоимостью ≥ 50 монет
- Кнопка «Торговаться» рядом с кнопкой «Купить/Продать»
- Можно пропустить и купить по стандартной цене

### Механика

#### Раунды

Торг состоит из 3-5 раундов (зависит от размера сделки):

| Сумма сделки | Раунды |
|--------------|--------|
| 50-99 монет | 3 |
| 100-199 монет | 4 |
| 200+ монет | 5 |

#### Структура раунда

Каждый раунд игрок видит текущее предложение торговца и выбирает одну из трёх тактик:

| Тактика | Описание | Эффект |
|---------|----------|--------|
| Жёсткая | «Это грабёж! За такое и 5 монет много» | Скидка −8-12%, но +20% шанс отказа |
| Умеренная | «Давай найдём разумную цену» | Скидка −4-6%, низкий шанс отказа (5%) |
| Уступка | «Ладно, твоя цена справедлива» | Скидка −1-2%, шанс отказа 0% |

После выбора тактики торговец реагирует:

```
┌─────────────────────────────────────────────────┐
│  Раунд 2/4                                      │
│                                                  │
│  Торговец: «120 монет за шёлк — последняя цена!»│
│  Текущая цена: 120 (базовая: 150)               │
│                                                  │
│  ┌──────────┐  ┌──────────┐  ┌──────────┐       │
│  │ 💪 Жёстко │  │ 🤝 Умерен│  │ 😌 Уступ │       │
│  │   −10%   │  │   −5%    │  │   −2%    │       │
│  │  Риск 25%│  │  Риск 5% │  │  Риск 0% │       │
│  └──────────┘  └──────────┘  └──────────┘       │
│                                                  │
│         [ Принять 120 монет ]                    │
└─────────────────────────────────────────────────┘
```

#### Кнопка «Принять»

В любой момент игрок может принять текущую цену и завершить торг. Если не принял и прошёл все раунды — сделка заключается по последней озвученной цене.

#### Отказ торговца

Если торговец «обижается» (накопленный шанс отказа превышен):

- Торговец уходит
- Товар НЕДОСТУПЕН для покупки в этом городе до следующего посещения
- Событие «Торговец обиделся» — −2 репутация в городе

Отказ не мгновенный: вероятность рассчитывается кумулятивно по раундам. Бросок происходит в конце каждого раунда.

### Модификаторы

Навыки и параметры игрока влияют на торг:

| Модификатор | Эффект |
|-------------|--------|
| Навык Торговля (0-100) | +0.1% скидки за единицу навыка (макс +10%) |
| Язык: Fluent | −5% к шансу отказа |
| Язык: Conversational | −2% к шансу отказа |
| Язык: None | +10% к шансу отказа, скидки ×0.5 |
| Репутация > 70 | −5% к шансу отказа, +2% к скидке |
| Репутация < 30 | +10% к шансу отказа |
| Спутник-торговец | +5% к скидке (новичок), +10% (опытный), +15% (мастер) |

### Формула

```
итоговая_скидка = базовая_скидка_тактики × (1 + навык_торговля / 1000) + бонус_спутника
шанс_отказа = базовый_шанс_тактики − языковой_бонус − репутационный_бонус
```

Скидка не может превысить 25% от базовой цены. При продаже логика зеркальная — игрок поднимает цену.

### Пример

Покупка шёлка (базовая цена 150 монет). Игрок: Торговля 40, Conversational, репутация 55.

| Раунд | Тактика | Скидка | Цена | Шанс отказа |
|-------|---------|--------|------|-------------|
| 1 | Жёсткая | −12% | 132 | 18% (20% − 2% язык) |
| 2 | Умеренная | −5% | 125 | 3% |
| 3 | Умеренная | −5% | 119 | 3% |
| 4 | Принять | — | **119** | — |

Итого: 119 вместо 150 (скидка 21%). Без торга заплатил бы 150.

## Мини-игра 2: Нарды (Backgammon)

### Концепция

Нарды (بازی نرد) — одна из древнейших настольных игр, родина — Персия. На Шёлковом пути нарды играли повсеместно: в караван-сараях, чайных домах, на привалах. В игре нарды — способ провести время в таверне с пользой: выиграть деньги и услышать полезные слухи.

### Когда доступен

- При посещении здания «Таверна» в любом городе
- Кнопка «Сыграть в нарды» на экране таверны
- Всегда опционально

### Механика

Это НЕ полноценная реализация нардов. Это упрощённая абстракция: серия решений на основе бросков кубиков.

#### Этапы партии

Партия состоит из 3 этапов (начало, середина, финал). На каждом этапе:

1. Бросок двух кубиков (d6 + d6)
2. Игрок выбирает ход из 2-3 вариантов
3. Результат определяет очки

#### Варианты хода

| Вариант | Описание | Когда выгоден |
|---------|----------|---------------|
| Агрессивный | Вывести фишки вперёд, рискуя побитием | При высоком броске (сумма ≥ 9) |
| Защитный | Укрепить позицию, заблокировать соперника | При среднем броске (5-8) |
| Хитрый | Оставить ловушку для соперника | При любом броске, но шанс 50/50 |

#### Очки и победа

| Этап | Агрессивный (успех/провал) | Защитный (успех/провал) | Хитрый (успех/провал) |
|------|---------------------------|-------------------------|------------------------|
| Начало | +3 / −1 | +1 / +1 | +2 / −2 |
| Середина | +4 / −2 | +2 / +1 | +3 / −3 |
| Финал | +5 / −3 | +2 / +2 | +4 / −4 |

Успех агрессивного хода: бросок ≥ 9. Защитного: бросок ≥ 5. Хитрого: бросок ≥ 7 (или навык Харизма смещает порог).

Победа: набрать больше очков, чем соперник (NPC бросает свои кубики скрыто, его стратегия определяется типом).

#### Типы соперников

| Тип | Стратегия NPC | Средние очки | Где встречается |
|-----|---------------|--------------|-----------------|
| Новичок | Случайные ходы | 4-6 | Караванные остановки, обычные города |
| Опытный | Защитная | 6-8 | Торговые узлы, ремесленные центры |
| Мастер | Агрессивная | 8-10 | Столицы, порты |
| Шулер | Хитрая (мошенничество) | 7-9* | Пограничные города |

*Шулер жульничает: при проигрыше может потребовать реванш или украсть монеты (событие).

### Ставки

| Тип ставки | Сумма | Доступность |
|------------|-------|-------------|
| Малая | 5-10 монет | Везде |
| Средняя | 20-30 монет | Торговые узлы и выше |
| Крупная | 50 монет | Столицы |

### Награды

| Результат | Награда |
|-----------|---------|
| Победа | Ставка ×2 + слух |
| Ничья | Ставка возвращается |
| Поражение | Потеря ставки |
| Победа над мастером | Ставка ×3 + редкий слух + «Игрок в нарды» (+2 Харизма на 5 дней) |

#### Слухи

Слух — информационная награда. При победе игрок узнаёт случайный факт:

| Тип слуха | Описание | Ценность |
|-----------|----------|----------|
| Цена товара | «В Самарканде шёлк сейчас стоит вдвое» | Раскрывает цену в соседнем городе |
| Дорожный эффект | «На дороге к Балху разбойники» | Раскрывает эффект на конкретном маршруте |
| Скрытый товар | «У антиквара в Бухаре видели лазурит» | Раскрывает редкий товар в конкретном городе |
| Квестовая подсказка | «На юге ищут торговца для особого поручения» | Раскрывает начало задания |

Тип слуха определяется случайно. Редкий слух (от мастера) раскрывает два факта вместо одного.

### Модификаторы

| Модификатор | Эффект |
|-------------|--------|
| Навык Харизма (0-100) | −1 к порогу «Хитрого» хода за каждые 20 ед. навыка |
| Язык: Fluent | Видны скрытые подсказки («Соперник нервничает» → он блефует) |
| Язык: None | Нет подсказок, соперник получает +1 к очкам |
| Репутация > 60 | Мастера соглашаются играть |
| Спутник-торговец | +1 к очкам (торговец подсказывает ходы шёпотом) |

### Мошенничество

При игре с шулером (20% шанс в пограничных городах):

- После проигрыша игрок может заметить мошенничество (шанс = Харизма / 2)
- Если заметил: выбор — потребовать деньги назад (конфликт) или уйти
- Конфликт: навык Харизма или Выживание. Успех = ставка ×3 + репутация. Провал = драка, −10 мораль, −5 здоровья

### Интерфейс

```
┌─────────────────────────────────────────────────┐
│  НАРДЫ — Этап 2/3                    Ставка: 20 │
│                                                  │
│  Ваш бросок: ⚄ ⚅ (11)                          │
│  Ваши очки: 5    Соперник: ~4-6                 │
│                                                  │
│  ┌──────────┐  ┌──────────┐  ┌──────────┐       │
│  │ ⚔️ Атака  │  │ 🛡️ Защита│  │ 🎭 Хитро │       │
│  │ +4 / −2  │  │ +2 / +1  │  │ +3 / −3  │       │
│  │ Нужно: 9+│  │ Нужно: 5+│  │ Нужно: 7+│       │
│  │  ✓ Успех │  │  ✓ Успех │  │  ✓ Успех │       │
│  └──────────┘  └──────────┘  └──────────┘       │

```

## Общие принципы дизайна

### Опциональность

Ни одна мини-игра не является обязательной. Игрок, который не хочет торговаться, покупает по стандартной цене. Игрок, который не играет в нарды, просто не заходит в таверну (или использует таверну только для слухов за монеты, как в базовой механике).

### Темп

Мини-игра не должна задерживать игрока дольше 60 секунд:

| Мини-игра | Среднее время |
|-----------|---------------|
| Торг (3 раунда) | 20-30 сек |
| Торг (5 раундов) | 40-50 сек |
| Нарды | 30-45 сек |

### Кулдаун

Чтобы мини-игры не превращались в гринд:

| Мини-игра | Ограничение |
|-----------|-------------|
| Торг | 1 раз за товар за посещение города |
| Нарды | 1 партия за посещение таверны (не более 3 партий в одном городе за визит) |

## Структура данных

### HaggleConfig (ScriptableObject)

```
HaggleConfig:
  minTradeValue: int               // 50 — порог для торга
  roundsByValue: RoundThreshold[]  // [{50, 3}, {100, 4}, {200, 5}]
  tactics: HaggleTactic[]          // Жёсткая, Умеренная, Уступка
  maxDiscount: float               // 0.25 (25%)
  refusalReputationPenalty: int    // −2
```

### HaggleTactic

```
HaggleTactic:
  id: string                       // "aggressive", "moderate", "concession"
  displayName: LocalizedString
  discountRange: Vector2           // (0.08, 0.12) для жёсткой
  refusalChance: float             // 0.20 для жёсткой
  icon: Sprite
```

### BackgammonConfig (ScriptableObject)

```
BackgammonConfig:
  stakes: StakeOption[]            // [{5, 10}, {20, 30}, {50, 50}]
  opponentTypes: OpponentType[]    // Новичок, Опытный, Мастер, Шулер
  rumorPool: RumorEntry[]          // Пул слухов
  cheaterChance: float             // 0.20 (в пограничных городах)
  maxGamesPerVisit: int            // 3
```

### OpponentType

```
OpponentType:
  id: string                       // "novice", "experienced", "master", "cheater"
  displayName: LocalizedString
  strategy: string                 // "random", "defensive", "aggressive", "cheating"
  scoreRange: Vector2Int           // (4, 6) для новичка
  availableCityTypes: CityType[]   // Где встречается
  requiredReputation: int          // 0, 0, 60, 0
```

### RumorEntry

```
RumorEntry:
  type: RumorType                  // Price, RoadEffect, HiddenGood, QuestHint
  text: LocalizedString            // Текст слуха
  targetCity: CityId               // Какой город раскрывает (опционально)
  targetRoute: string              // Какой маршрут раскрывает (опционально)
```

## Интеграция с существующими системами

| Система | Файл | Точка интеграции |
|---------|------|------------------|
| Торговля | смотри Экономика | Торг модифицирует buy_coef / sell_coef для конкретной сделки |
| Навыки | смотри Навыки | Торговля → торг, Харизма → нарды |
| Языки | смотри Языки | Уровень языка влияет на шанс отказа и подсказки |
| Спутники | смотри Спутники | Торговец-спутник усиливает торг |
| Репутация | смотри Репутация | Влияет на доступ к мастерам, шанс отказа |
| Таверна | смотри Города | Нарды как активность в таверне |
| Разведка | смотри Карта и перемещение | Слухи раскрывают скрытую информацию |

### Приоритет реализации

1. Торг — базовая механика (3 тактики, модификаторы навыков)
2. Нарды — базовая механика (3 этапа, 3 варианта хода)
3. Слухи из нард (интеграция с системой разведки)
4. Мошенничество в нардах
5. Полировка UI и анимации
