# Торговые гильдии

> **Перспективный дизайн.** Этот документ описывает систему, которая планируется к реализации в будущем. Механики могут измениться по результатам тестирования.

## Обзор

Торговые гильдии — семь фракций, контролирующих торговлю на Великом шёлковом пути. Каждая гильдия объединяет города определённого региона, имеет уникальную культуру, специализацию и систему ценностей.

Гильдии расширяют систему репутации (смотри Репутация). Общая репутация (единый параметр 0-100) остаётся глобальным показателем известности игрока. Гильдейская карма — отдельная механика, отражающая отношения игрока с каждой из семи фракций.

Основная идея: игрок не может быть другом всех. Гильдии конкурируют между собой, и помощь одной может навредить отношениям с другой. Это создаёт стратегический выбор: через какие территории строить маршрут и с кем поддерживать отношения.

## Семь гильдий

### 1. Ханьские торговцы (漢商)

**Историческая основа.** Китайская государственная торговля, система гильдий 行 (хан), государственные монополии на соль и железо. Торговля контролировалась двором: без императорского разрешения вывоз стратегических товаров был невозможен.

**Ценности:** Порядок, имперская документация, верность престолу, иерархия.

**Специализация:** Шёлк, фарфор, чай, лаковые изделия, бумага.

**Характер.** Ханьские торговцы — государственная машина. Они не торгуют ради прибыли отдельных купцов, а продвигают интересы Поднебесной. Строгая иерархия: без печати начальника каравана невозможно получить крупный заказ. Ценят бумагу и документацию — контракт для них важнее рукопожатия. К чужакам относятся свысока, но уважают тех, кто играет по их правилам.

**Бонусы при высокой карме:**
- Доступ к императорским заказам (крупные поставки шёлка и фарфора)
- Охрана гарнизонов на дорогах Центрального Китая (−10 опасность)
- Скидка на пошлины в китайских городах (−30%)
- Доступ к мастерским для крафта лаковых изделий

### 2. Тибетское братство (བོད་ཚོང)

**Историческая основа.** Тибетская торговля через буддийские монастырские сети. Чайно-лошадиный путь (茶马古道) — один из древнейших торговых маршрутов мира. Монахи были не только духовными наставниками, но и посредниками в торговле.

**Ценности:** Духовность, честность, изоляция, умеренность.

**Специализация:** Яки, мускус, целебные травы, религиозные артефакты, нефрит (Хотан).

**Города (4):**

| Город | Регион | Тип города | Роль в гильдии |
|-------|--------|------------|----------------|
| Лицзян | Юго-Западный Китай | Обычный | Торговые ворота в Тибет |
| Лхаса | Юго-Западный Китай | Святой город | Духовный центр, штаб-квартира |
| Хотан | Западный край | Сырьевой | Нефритовые копи |
| Дуньхуан | Западный край | Святой город | Пещеры Могао, перекрёсток путей |

**Характер.** Самая малочисленная гильдия, но с сильнейшим духовным авторитетом. Братство не стремится к масштабной торговле — их интересует обмен: чай снизу, лошади и мускус сверху. Монахи-торговцы оценивают чужаков не по богатству, а по поступкам. Обман тибетского брата — тяжкий грех, который запоминают надолго. Но если завоевать доверие — помогут в любой беде, даже в ущерб себе.

**Бонусы при высокой карме:**
- Бесплатный ночлег и лечение в монастырях
- Доступ к целебным травам (бесплатное лечение болезней)
- Проводники по горным перевалам (−15 опасность на высокогорных дорогах)
- Доступ к нефриту по себестоимости в Хотане

### 3. Согдийский союз (粟特商盟)

**Историческая основа.** Согдийцы — профессиональное торговое сословие Шёлкового пути. Система сабао (торговых старост), многоязычные посредники, банковские сети, караванные колонии по всему маршруту. Согдийские торговые поселения (наны) существовали от Чанъаня до Константинополя.

**Ценности:** Взаимопомощь, караванная культура, торговые секреты, адаптивность.

**Специализация:** Посредничество во всех товарах. Также: лазурит, лошади, металлоизделия.

| Куча | Западный край | Кар. остановка | Перевалочный пункт |
| Аксу | Западный край | Кар. остановка | Перевалочный пункт |
| Кашгар | Западный край | Торговый узел | Главный перекрёсток маршрутов |

**Характер.** Согдийцы — «кровь Шёлкового пути». Они говорят на всех языках, знают все маршруты и торгуют всем. Их сила — в сети: каждый согдийский купец знает согдийца в следующем городе. Главный принцип — взаимовыручка: помоги согдийцу, и его родственник поможет тебе через три города. Не ценят верность одному правителю — ценят верность торговле.

**Бонусы при высокой карме:**
- Сеть информаторов: актуальная информация о ценах в соседних городах
- Торговые кредиты (займ до 200 монет с отдачей через 30 дней)
- Согдийские караван-сараи: улучшенный привал (+15 мораль, −5 опасность)
- Посредничество: возможность продать товар по цене следующего города

### 4. Персидский караван (کاروان ایرانی)

**Историческая основа.** Традиция Персидской царской дороги, сассанидские торговые сети, позже — исламская купеческая традиция. Персидские караваны славились надёжностью: контракт с персидским купцом выполнялся даже ценой убытка.

**Ценности:** Честь контракта, долгосрочные отношения, утончённость, мастерство.

**Специализация:** Ковры, металлы, стеклянные изделия, драгоценные камни, духи.

| Балх | Средняя Азия | Сырьевой | Восточные ворота Персии |
| Мерв | Средняя Азия | Обычный | Военная крепость, форпост |
| Мешхед | Персия | Обычный | Паломнический центр |
| Нишапур | Персия | Обычный | Центр бирюзы и ремёсел |

| Табриз | Персия | Торговый узел | Штаб-квартира, главный рынок |

**Характер.** Персидские купцы — аристократы торговли. Они не торопятся, не суетятся и не торгуются в базарном стиле. Контракт для перса — вопрос чести рода. Нарушить слово — хуже, чем потерять деньги. Ценят долгосрочные отношения: первая сделка всегда невыгодна для обеих сторон, зато десятая делает обоих богатыми. К новичкам относятся холодно, но если заслужить уважение — персидский партнёр останется верным до конца.

**Бонусы при высокой карме:**
- Контрактная система: фиксированные цены на товары (защита от колебаний рынка)
- Доступ к персидским мастерским (крафт ковров и ювелирных изделий)
- Военная охрана караванов через Персию (−15 опасность)
- Доступ к библиотеке Багдада (бонус к навыкам +5)

### 5. Индийское сообщество (भारतीय संघ)

**Историческая основа.** Торговля Индийского океана, буддийские торговые сети, система шрени (гильдий). Индийские купцы торговали специями, хлопком и драгоценными камнями задолго до Шёлкового пути. Кастовая система определяла, кто и чем может торговать.

**Ценности:** Ненасилие (ахимса), религиозный долг (дхарма), справедливая сделка, кастовая торговля.

**Специализация:** Специи, хлопок, драгоценные камни, слоновая кость, сахар, индиго.

**Города (7):**

| Город | Регион | Тип города | Роль в гильдии |
|-------|--------|------------|----------------|
| Кабул | Индия | Пограничный | Горный торговый пост |
| Таксила | Индия | Обычный | Древний центр учёности |
| Дели | Индия | Столица | Штаб-квартира, политический центр |
| Патна | Индия | Обычный | Речной торговый узел |
| Аллахабад | Индия | Святой город | Религиозный центр |
| Тамралипти | Индия | Порт | Морской порт на востоке |
| Камбей | Индия | Порт | Главный порт на западе |

**Характер.** Индийские купцы — терпеливые и принципиальные. Они не обманывают (дхарма запрещает), но и не дают себя обмануть. Индийское сообщество самое нейтральное из всех гильдий: они торгуют со всеми и не вступают в конфликты. Однако обидеть индийского торговца — значит закрыть себе доступ ко всему индийскому маршруту: сеть шрени передаёт информацию быстро.

**Бонусы при высокой карме:**
- Доступ к редким специям по сниженным ценам (−20%)
- Благословение храмов: +10 мораль при посещении индийских городов
- Морская торговля: возможность отправить товар морем из Камбея в Хормуз или Айдхаб
- Медицинские знания: бесплатное лечение болезней в индийских городах

### 6. Арабская лига (رابطة التجار)

**Историческая основа.** Доисламская мекканская торговля, позже — исламская купеческая традиция. Морская торговля на дау (парусных кораблях), контроль торговли благовониями. Хадж создал инфраструктуру, которая обслуживала и торговлю.

**Ценности:** Гостеприимство, вера, суровость к врагам, коммерция паломничества.

**Специализация:** Благовония, ладан, мирра, финики, лошади, жемчуг.

**Города (5):**

| Город | Регион | Тип города | Роль в гильдии |
|-------|--------|------------|----------------|
| Хормуз | Аравия | Порт | Морские ворота Персидского залива |
| Сухар | Аравия | Порт | Центр морской торговли |
| Медина | Аравия | Святой город | Религиозный центр |
| Мекка | Аравия | Святой город | Штаб-квартира, духовное сердце |
| Айдхаб | Аравия | Порт | Красноморский порт |

**Характер.** Арабские купцы живут по закону пустыни: гость священен, друг защищён, враг уничтожен. Гостеприимство — абсолютный долг: даже врагу дадут воду и кров на три дня. Но если вы обманули арабского торговца — вас запомнят навсегда. Арабская лига контролирует маршрут через Аравию и Красное море; без их расположения путь через эти земли становится крайне дорогим и опасным.

**Бонусы при высокой карме:**
- Гостеприимство пустыни: бесплатный привал в арабских городах (+10 мораль, восполнение припасов)
- Доступ к маршрутам паломников (безопасные дороги между Меккой, Мединой и Айдхабом)
- Скидка на благовония и экзотические товары (−15%)
- Морские перевозки: дау между Хормузом, Сухаром и Айдхабом

### 7. Средиземноморская лига (Μεσογειακή Ένωση)

**Историческая основа.** Византийская торговая система, левантийская коммерция, египетская торговля Фатимидов. Константинополь — конечная точка Шёлкового пути и ворота в Европу. Контроль Босфора давал Византии уникальное торговое преимущество.

**Ценности:** Дипломатия, традиции, западные связи, морское мастерство.

**Специализация:** Стекло, красители, оливковое масло, вино, оружие, текстиль.

**Города (8):**

| Город | Регион | Тип города | Роль в гильдии |
|-------|--------|------------|----------------|
| Алеппо | Левант | Торговый узел | Крупнейший базар Леванта |
| Дамаск | Левант | Ремесленный | Центр дамасской стали и ремёсел |
| Антиохия | Левант | Пограничный | Форпост на востоке |
| Триполи | Левант | Порт | Портовый город |
| Газа | Левант | Обычный | Торговый перекрёсток |
| Каир | Левант | Столица | Экономический центр Египта |
| Трабзон | Византия | Порт | Черноморский порт |
| Константинополь | Византия | Столица | Штаб-квартира, конец Шёлкового пути |

**Характер.** Средиземноморская лига — самая политизированная гильдия. Здесь каждая сделка имеет второе дно: кому выгодна, какой альянс усиливает, какого конкурента ослабляет. Византийская дипломатия знаменита сложностью — но и результаты впечатляют. Лига контролирует конечный пункт Шёлкового пути: товары, прибывшие в Константинополь, уходят в Европу по ценам, которые назначает лига. Без расположения лиги цена продажи в Константинополе существенно падает.

**Бонусы при высокой карме:**
- Максимальные цены продажи в Константинополе (+15% к продажной цене)
- Дипломатический иммунитет: городские модификаторы не влияют на игрока в городах лиги
- Доступ к европейским заказам (уникальные высокомаржинальные контракты)
- Морские маршруты: перевозка между Триполи, Каиром и Трабзоном

## Механика репутации (кармы) гильдий

### Шкала

| Параметр | Значение |
|----------|----------|
| Диапазон | от −100 до +100 |
| Стартовое значение | 0 (нейтральный) |
| Отдельный для каждой гильдии | Да (7 независимых значений) |
| Затухание | Нет (карма не уменьшается со временем) |

Отличие от общей репутации (смотри Репутация): общая репутация (0-100) отражает глобальную известность, затухает к 25 и влияет на все города. Гильдейская карма (−100..+100) отражает отношения с конкретной фракцией, не затухает и влияет только на города этой гильдии.

### Уровни отношений

| Диапазон | Статус | Эффект |
|----------|--------|--------|
| −100..−51 | Враг | Доступ ограничен (см. ниже), +50% цены в городах гильдии, здания гильдии закрыты, враждебные мини-события |
| −50..−21 | Недоверие | +25% цены покупки в городах гильдии, −15% цены продажи, слухи в тавернах неполные, побочные задания недоступны |
| −20..+20 | Нейтральный | Стандартные цены и доступ. Гильдия не помогает и не мешает |
| +21..+50 | Доверие | −10% цены покупки, +10% цены продажи, доступ к побочным заданиям гильдии, полные слухи |
| +51..+100 | Союзник | −20% цены покупки, +20% цены продажи, уникальные бонусы гильдии (см. описание каждой гильдии), новые варианты в событиях, охрана на дорогах гильдии |

### Влияние на игровые системы

**Торговля.** Модификатор кармы умножает цены в городах гильдии. Применяется поверх коэффициентов (смотри Экономика) и общей репутации:

```
итоговая_цена = базовая_цена × коэф_типа_города × экзотичность × репутация × карма_гильдии
```

**Доступ к зданиям.** При статусе «Враг» здания Гильдия и Мастерская в городах фракции закрыты. Рынок, Караван-сарай, Таверна и Лекарь доступны всегда — даже враги не могут отказать торговцу в базовых услугах.

**События.** Статус с гильдией является условием для событий:

```
conditions:
  - type: MinGuildKarma, target: "sogdian_union", value: 30
  - type: MaxGuildKarma, target: "persian_caravan", value: -30
```

**Задания.** Квестовые ветки гильдий требуют минимальной кармы для каждого этапа:

| Этап | Минимальная карма |
|------|-------------------|

## Механика «Враг» — без софт-лока

Статус «Враг» с гильдией (карма < −50) не блокирует доступ к городам полностью. Игрок всегда может продолжить путешествие. Механика мягкого ограничения работает следующим образом.

### При входе в город вражеской гильдии

Стража останавливает караван. Игроку доступны три варианта:

**1. Заплатить взятку.** Стоимость: 10% от текущих денег, но не менее 20 монет. Гарантированный вход. Карма не меняется.

**2. Убедить стражу.** Требуется навык Харизма > 30. Шанс успеха: 50% + (Харизма × 0.5%). При успехе — бесплатный вход, карма +1. При провале — отказ (можно заплатить или уйти).

**3. Уйти.** Караван разворачивается. Доступны ближайшие дороги к другим городам. Потеря: −5 мораль (разочарование каравана).

### Внутри вражеского города

Если игрок всё же попал в город вражеской гильдии:

| Эффект | Значение |
|--------|----------|
| Цены покупки | +50% |
| Цены продажи | −30% |
| Здания гильдии | Закрыты (Гильдия, Мастерская) |
| Базовые здания | Открыты (Рынок, Караван-сарай, Таверна, Лекарь) |
| Храм, Библиотека | Открыты (религия и знания не подчиняются гильдии) |
| Школа языков | Открыта |
| Мини-события | Враждебные (кража, угрозы, ультиматумы) |

### Враждебные мини-события в городе

При посещении города вражеской гильдии с шансом 30% за каждое посещённое здание срабатывает враждебное мини-событие:

- **«Вор на рынке»** — кража товара (потеря случайного предмета, 1 шт.)
- **«Угрозы в таверне»** — опасность +10, мораль −5
- **«Подстроенная драка»** — опасность +15, навык(выживание, шанс 40%) или деньги −20
- **«Испорченный товар»** — случайный товар в инвентаре теряет 50% стоимости

## Матрица отношений между гильдиями

Гильдии не существуют в изоляции. Исторические связи, торговая конкуренция и культурные различия создают систему альянсов и соперничества.

### Обозначения

- **Союз (+)** — гильдии сотрудничают. Помощь одной приносит бонус второй.
- **Нейтралитет (0)** — гильдии не имеют особых отношений.
- **Соперничество (−)** — гильдии конкурируют. Помощь одной вызывает недовольство второй.

### Матрица (7x7)

|  | Ханьские | Тибетское | Согдийский | Персидский | Индийское | Арабская | Средиземн. |
|--|----------|-----------|------------|------------|-----------|----------|------------|
| **Ханьские** | — | − | + | 0 | 0 | 0 | 0 |
| **Тибетское** | − | — | 0 | 0 | + | 0 | 0 |
| **Согдийский** | + | 0 | — | − | 0 | 0 | 0 |
| **Персидский** | 0 | 0 | − | — | 0 | − | + |
| **Индийское** | 0 | + | 0 | 0 | — | 0 | 0 |
| **Арабская** | 0 | 0 | 0 | − | 0 | — | − |
| **Средиземн.** | 0 | 0 | 0 | + | 0 | − | — |

### Историческое обоснование

**Ханьские + Согдийский (Союз).** Согдийцы были главными торговыми партнёрами Китая. Согдийские колонии в китайских городах обеспечивали логистику Шёлкового пути. Взаимовыгодный симбиоз: Китай производит товар, согдийцы доставляют.

**Ханьские − Тибетское (Соперничество).** Пограничные конфликты Тан и Тибета. Борьба за контроль над Западным краем. Чайно-лошадиная торговля была одновременно и коммерцией, и инструментом давления.

**Согдийский − Персидский (Соперничество).** Прямая торговая конкуренция за контроль маршрутов через Среднюю Азию и Персию. Согдийцы были посредниками, персы хотели торговать напрямую.

**Персидский − Арабская (Соперничество).** Сложное соперничество: религиозное (зороастризм vs ислам), культурное и торговое. Арабское завоевание Персии создало напряжение, сохраняющееся веками.

**Персидский + Средиземн. (Союз).** Византия и Персия, несмотря на военные конфликты, вели активную торговлю. Персидские товары были основой левантийских базаров. Экономические интересы перевешивали политические.

**Арабская − Средиземн. (Соперничество).** Конкуренция за контроль над Красным морем и морскими путями в Индию. Крестовые походы обострили противоречия, но торговля продолжалась даже во время войн.

**Тибетское + Индийское (Союз).** Буддийские связи создали прочную торговую сеть между Тибетом и Индией. Монастыри были одновременно храмами и торговыми факториями.

### Влияние на карму

Когда игрок совершает действие, влияющее на карму с одной гильдией, матрица отношений определяет побочный эффект:

| Действие | Карма с гильдией-союзником | Карма с гильдией-соперником |
|----------|---------------------------|----------------------------|
| Положительное (+N) с гильдией A | +2 с союзником A | −2 с соперником A |
| Отрицательное (−N) с гильдией A | −2 с союзником A | +2 с соперником A |

Побочный эффект фиксирован (+2 / −2) и не зависит от величины исходного изменения. Это не каскадный процесс — вторичные изменения не вызывают третичных.

**Пример.** Игрок выполнил задание для Согдийского союза (+10 карма). Через матрицу: Ханьские торговцы (союзник) получают +2. Персидский караван (соперник) получает −2. Остальные гильдии (нейтралитет) не затрагиваются.

## Квестовые ветки гильдий

Каждая гильдия предлагает линейную цепочку из 5 заданий. Задания становятся доступны по мере роста кармы. Активная квестовая ветка может быть только одна от каждой гильдии.

### Ханьские торговцы — «Печать дракона»

**Этап 1. Императорская канцелярия** (карма 0+, город: Чанъань, здание: Гильдия)
Чиновник торгового приказа предлагает доставить партию казённого шёлка в Ланьчжоу. Простая проверка надёжности: довезти 5 единиц шёлка за 15 дней без потерь. Награда: +10 карма, 40 монет.

**Этап 2. Список запретов** (карма +10, город: Ланьчжоу, здание: Казармы)
Начальник гарнизона просит расследовать контрабанду запрещённых товаров через Юймэнь. Нужно добраться до Юймэня и найти контрабандиста (событие в таверне). Выбор: сдать его страже (+карма) или отпустить за взятку (+деньги, −карма). Награда: +12 карма, доступ к товарам по сниженной пошлине.

**Этап 3. Шёлковый путь императора** (карма +25, город: Пекин, здание: Гильдия)
Императорский двор хочет наладить прямой торговый маршрут до Кашгара, минуя посредников. Игрок должен пройти весь путь от Пекина до Кашгара, заключая торговые контракты в каждом городе (Ланьчжоу, Цзюцюань, Юймэнь, Аньси, Турфан, Куча, Аксу). Награда: +15 карма, 150 монет, титул «Императорский посланник».

**Этап 4. Предательство в Юймэне** (карма +40, событие: при входе в Юймэнь)
Местный начальник гарнизона плетёт заговор: перенаправляет караваны в обход, обкладывая собственными пошлинами. Игрок обнаруживает схему. Выбор: доложить в Пекин (длинный путь, +20 карма, −деньги на дорогу) или вступить в долю (короткий, +100 монет, −25 карма).

**Этап 5. Нефритовая печать** (карма +60, город: Чанъань, здание: Гильдия)
Императорский двор предлагает стать официальным торговым представителем — получить Нефритовую печать. Для этого нужно доставить дипломатическую миссию из Чанъаня в Самарканд и обратно (событие с согдийскими торговцами). Награда: постоянный статус «Носитель печати», −50% пошлины во всех китайских городах, уникальная стартовая возможность при следующем забеге.

### Тибетское братство — «Путь белого лотоса»

**Этап 1. Чай для монастыря** (карма 0+, город: Лицзян, здание: Таверна)
Монах из Лхасы ищет торговца, готового доставить чай в монастырь. Простая доставка: 3 единицы чая из Лицзяна в Лхасу. Горная дорога опасна, но монах обещает духовное благословение. Награда: +10 карма, бесплатное лечение на 10 дней.

**Этап 2. Нефрит Хотана** (карма +10, город: Лхаса, здание: Храм)
Братство просит отправиться в Хотан и оценить новую жилу нефрита. Добраться до Хотана, найти камень определённого качества (событие на месте), привезти образец обратно. Опасность: дорога через горы. Награда: +12 карма, доступ к нефриту по сниженной цене.

**Этап 3. Караван мускуса** (карма +25, город: Лхаса, здание: Храм)
Братство поручает крупную торговую операцию: собрать мускус и целебные травы по тибетским монастырям (Лхаса, Дуньхуан) и доставить в Кашгар для продажи. Часть прибыли идёт на реставрацию пещер Могао. Награда: +15 карма, 120 монет, проводник по горным дорогам (бесплатный спутник на 20 дней).

**Этап 4. Раскол братства** (карма +40, событие: при посещении Дуньхуана)
Часть монахов хочет закрыть торговые пути через Тибет — «мирские богатства развращают». Другая часть считает, что торговля кормит монастыри. Игрок оказывается в центре конфликта. Выбор: поддержать изоляционистов (братство сохранит чистоту, но торговля сократится: −15% товаров в тибетских городах, +15 карма) или реформаторов (торговля расширится: +15% товаров, +10 карма, но −5 карма от изоляционистов, которые уйдут).

**Этап 5. Хранитель перевалов** (карма +60, город: Лхаса, здание: Храм)
Настоятель главного монастыря предлагает стать «Хранителем перевалов» — мирским защитником торговых путей Тибета. Для этого нужно пройти весь тибетский маршрут (Лицзян → Лхаса → Хотан → Дуньхуан) за один забег. Награда: постоянный статус, бесплатный отдых и лечение во всех тибетских городах, уникальное событие «Благословение гор» (−20 опасность на высокогорных дорогах).

### Согдийский союз — «Серебряная нить»

**Этап 1. Письмо в Бухару** (карма 0+, город: Кашгар, здание: Гильдия)
Согдийский купец просит доставить письмо деловому партнёру в Бухару. Простая доставка, но по дороге возникнет событие: бандиты хотят именно это письмо (торговые секреты). Выбор: отдать (−10 карма) или защитить (бой/откуп). Награда: +10 карма, информация о ценах в 3 ближайших городах.

**Этап 2. Сеть сабао** (карма +10, город: Самарканд, здание: Гильдия)
Старейшина Союза просит наладить связь между тремя согдийскими факториями: Турфан, Куча, Аксу. Нужно посетить все три, решить проблему каждой (доставка товара, устранение спора, помощь с бандитами). Награда: +12 карма, доступ к согдийской сети информаторов.

**Этап 3. Банк Самарканда** (карма +25, город: Самарканд, здание: Гильдия)
Согдийский банк хочет установить кредитную линию до Багдада. Игрок должен пройти маршрут Самарканд → Мерв → Мешхед → Нишапур → Рей → Багдад, в каждом городе оставляя залог (50 монет × 5 = 250 монет, возвращаются по завершении). В Багдаде — переговоры с персидскими банкирами (навык Торговля). Награда: +15 карма, 300 монет (возврат залогов + процент), доступ к кредитам Союза.

**Этап 4. Предатель среди своих** (карма +40, событие: при входе в Бухару)
Один из согдийских старейшин продаёт маршрутные карты Персидскому каравану. Игрок обнаруживает это через перехваченное письмо (событие). Выбор: разоблачить открыто (справедливость, +15 карма, но предатель сбегает и создаёт проблемы позже) или подстроить ловушку (хитрость, +20 карма, но нужно пожертвовать 100 монет на приманку).

**Этап 5. Глава каравана** (карма +60, город: Самарканд, здание: Гильдия)
Совет старейшин предлагает игроку стать одним из них — войти в Круг сабао. Для доказательства нужно организовать Великий караван: собрать товары в 5 городах Союза и продать их с прибылью > 500 монет в городах за пределами территории Союза. Награда: постоянный статус «Сабао», торговые кредиты до 500 монет, посредничество (продажа по ценам удалённых городов).

### Персидский караван — «Контракт крови»

**Этап 1. Испытание контрактом** (карма 0+, город: Табриз, здание: Гильдия)
Персидский купец предлагает первый контракт: доставить ковры из Табриза в Багдад за 10 дней. Просто, но строгий дедлайн. Опоздание = провал. Награда: +10 карма, 50 монет.

**Этап 2. Турецкая бирюза** (карма +10, город: Нишапур, здание: Таверна)
Старший караванщик просит добыть бирюзу в Нишапуре и доставить в Табриз для ювелира. Проблема: месторождение контролируют бандиты (событие с боем или переговорами). Награда: +12 карма, бирюза (3 шт.), доступ к ювелирной мастерской.

**Этап 3. Караван через пустыню** (карма +25, город: Мерв, здание: Караван-сарай)
Персидский караван нуждается в охране на маршруте Мерв → Мешхед → Нишапур. Дорога через пустыню, 3 обязательных события (буря, бандиты, нехватка воды). Каждое событие имеет «персидский» вариант выбора (доступен только при активном задании). Награда: +15 карма, 180 монет, военная охрана на 15 дней.

**Этап 4. Контрактная война** (карма +40, событие: при входе в Рей)
Два влиятельных персидских купеческих дома спорят о контроле торгового маршрута через Рей. Оба хотят нанять игрока как арбитра. Выбор: поддержать дом Фирузан (традиционалисты: +15 карма, но цены на ковры вырастут на 10%), поддержать дом Шапур (реформаторы: +10 карма, цены на металл упадут на 10%), или найти компромисс (навык Харизма > 50: +20 карма, обе стороны довольны).

**Этап 5. Страж контракта** (карма +60, город: Табриз, здание: Гильдия)
Глава каравана предлагает стать «Стражем контракта» — гарантом исполнения торговых соглашений. Финальное испытание: заключить контракт между Персидским караваном и Средиземноморской лигой на поставку ковров в Константинополь. Требуется карма > +30 с обеими фракциями. Награда: постоянный статус, фиксированные контрактные цены, военная охрана на персидских дорогах.

### Индийское сообщество — «Колесо дхармы»

**Этап 1. Специи из Камбея** (карма 0+, город: Дели, здание: Гильдия)
Глава шрени (торговой гильдии) просит доставить специи из Камбея в Дели. Простая торговая операция, но по дороге — событие: больной ребёнок в деревне просит лекарство. Лекарство — в грузе специй. Выбор: отдать часть груза (−товар, +5 карма сверх награды) или отказать (−3 карма). Награда: +10 карма, 30 монет.

**Этап 2. Путь ахимсы** (карма +10, город: Аллахабад, здание: Храм)
Паломник просит сопроводить религиозную процессию из Аллахабада в Таксилу. Обязательное условие: ни одно событие по пути нельзя решать насилием. Все боевые варианты заблокированы — только дипломатия и деньги. Награда: +12 карма, благословение (+5 Харизма на 20 дней).

**Этап 3. Алмазная дорога** (карма +25, город: Камбей, здание: Порт)
Индийские купцы хотят наладить сухопутный маршрут для драгоценных камней от Камбея до Кабула (альтернатива морскому пути). Игрок прокладывает маршрут, договаривается с местными правителями в каждом городе (Камбей → Дели → Таксила → Кабул). В Кабуле — переговоры с пограничными племенами (событие). Награда: +15 карма, драгоценные камни (3 шт.), доступ к индийским морским перевозкам.

**Этап 4. Раскол шрени** (карма +40, событие: при входе в Дели)
Два клана шрени спорят о кастовых правилах торговли: клан Вайшья хочет сохранить традиции (только определённые касты торгуют определёнными товарами), клан Шудра требует равных прав. Выбор: поддержать традиции (+15 карма, но ассортимент в индийских городах ограничен), поддержать реформу (+10 карма, ассортимент расширяется, но −5 карма от традиционалистов), найти компромисс (навык Харизма > 45: +18 карма).

**Этап 5. Махараджа торговли** (карма +60, город: Дели, здание: Гильдия)
Совет шрени предлагает стать почётным членом — «Махараджа торговли» (Ваниджья Раджа). Финальное испытание: организовать караван благотворительности — доставить продовольствие и лекарства в города, пострадавшие от засухи или чумы (3 города с соответствующими модификаторами). Награда: постоянный статус, скидки на специи и камни, бесплатное лечение, морские перевозки.

### Арабская лига — «Клятва пустыни»

**Этап 1. Ладан для Медины** (карма 0+, город: Хормуз, здание: Таверна)
Арабский купец ищет надёжного человека для доставки ладана из Хормуза в Медину. Путь через пустыню (Хормуз → Сухар → Медина). Событие в пути: песчаная буря и необходимость выбирать между грузом и людьми. Награда: +10 карма, гостеприимство в Медине (бесплатный отдых).

**Этап 2. Жемчуг Персидского залива** (карма +10, город: Сухар, здание: Порт)
Старейшина лиги просит добыть партию жемчуга. Нужно нанять ныряльщиков (событие в Сухаре), затем доставить жемчуг в Мекку. На маршруте — пираты (событие). Награда: +12 карма, жемчуг (2 шт.), доступ к маршрутам паломников.

**Этап 3. Караван паломников** (карма +25, город: Мекка, здание: Храм)
Лига просит организовать торговый караван, совмещённый с паломничеством: Мекка → Медина → Айдхаб → Каир. Особенность: среди паломников есть шпион из Средиземноморской лиги (событие по пути). Выбор: разоблачить (бой или навык Харизма), игнорировать, или использовать для дезинформации. Награда: +15 карма, 140 монет, безопасные маршруты через Аравию.

**Этап 4. Раскол веры и торговли** (карма +40, событие: при входе в Мекку)
Религиозные лидеры осуждают «чрезмерное обогащение» торговцев лиги. Часть купцов хочет подчиниться и ограничить торговлю, часть — сохранить коммерческую свободу. Выбор: поддержать религиозных лидеров (+15 карма, но торговые ограничения в арабских городах: +10% цены), поддержать купцов (+10 карма, цены стабильны, но −5 карма от религиозной фракции), найти баланс (навык Харизма > 50: +18 карма, все довольны).

**Этап 5. Шейх торговых ветров** (карма +60, город: Мекка, здание: Гильдия)
Совет лиги предлагает стать «Шейхом торговых ветров» — покровителем морской торговли. Финальное испытание: организовать морской торговый маршрут Хормуз → Сухар → Айдхаб, обеспечив охрану от пиратов и договорившись с портовыми властями. Награда: постоянный статус, бесплатные морские перевозки, скидка на все арабские товары, уникальный доступ к благовониям.

### Средиземноморская лига — «Пурпур и золото»

**Этап 3. Путь в Константинополь** (карма +25, город: Каир, здание: Гильдия)

Выбор: поддержать монополию (+15 карма с лигой, −10 карма с Ханьскими, −10 карма с Согдийским), противодействовать (+10 карма с Ханьскими и Согдийским, −15 карма с лигой), или предложить квоту — компромисс (навык Торговля > 50: +10 карма со всеми).

**Этап 5. Легат торговли** (карма +60, город: Константинополь, здание: Гильдия)

Финальное испытание: организовать Великий базар в Константинополе, привлекая товары с каждого отрезка Шёлкового пути (минимум по одному уникальному товару из 5 разных регионов). Награда: постоянный статус, максимальные цены в Константинополе, европейские контракты, дипломатический иммунитет.

## Новые опции в событиях при высокой репутации

При карме > +30 с гильдией в событиях на территории этой гильдии появляются дополнительные варианты выбора.

### 1. Ханьские торговцы — «Засада в пустыне»

Событие: бандиты перекрыли дорогу в пустыне (стандартное событие «Засада в пустыне»).

Стандартные варианты:
1. Сражаться
2. Бежать
3. Откупиться

**Новый вариант (карма > +30 с Ханьскими):**
4. *«Показать императорскую грамоту»* — достаёте документ с печатью. Бандиты видят знаки императорской канцелярии и отступают. Результат: опасность −10, карма +2. Никаких потерь.

### 2. Тибетское братство — «Горная болезнь»

Событие: воздух разрежен, люди задыхаются (стандартное событие «Горная болезнь»).

Стандартные варианты:
1. Медленный подъём
2. Быстрый проход
3. Обходной путь

**Новый вариант (карма > +30 с Тибетским братством):**
4. *«Попросить монахов о помощи»* — братья из ближайшего монастыря приносят целебные травы и проводят караван по безопасной тропе. Результат: еда +5, опасность −10, навык(выживание +5). Нет негативных последствий.

### 3. Согдийский союз — «Караван-соперник»

Событие: большой караван с вооружённой охраной (стандартное событие «Караван-соперник»).

Стандартные варианты:
1. Торговать
2. Обогнать
3. Договориться [навык: торговля >= 2]

**Новый вариант (карма > +30 с Согдийским союзом):**
4. *«Связаться через сеть сабао»* — согдийская сеть подтверждает вашу репутацию. Караван-соперник предлагает совместный маршрут: объединённые караваны безопаснее. Результат: опасность −15, деньги +25, навык(торговля +10).

### 4. Персидский караван — «Прибрежные пираты»

Событие: головорезы нападают из-за скал (стандартное событие «Прибрежные пираты»).

Стандартные варианты:
1. Сражаться
2. Бежать
3. Заплатить выкуп

**Новый вариант (карма > +30 с Персидским караваном):**
4. *«Вызвать персидскую охрану»* — ваш статус в Персидском караване позволяет призвать военный эскорт. Отряд прибывает и разгоняет пиратов. Результат: опасность −20, карма +3. Никаких потерь, но эскорт уходит (+5 к опасности через 3 дня).

### 5. Индийское сообщество — «Заблудший путник»

Событие: измождённый путник с пустой флягой (стандартное событие «Заблудший путник»).

Стандартные варианты:
1. Помочь
2. Пройти мимо
3. Вылечить [спутник: лекарь]

**Новый вариант (карма > +30 с Индийским сообществом):**
4. *«Пригласить в индийское подворье»* — ближайшее индийское подворье (дхармашала) примет путника и позаботится о нём. Результат: репутация +8, карма +3, путник оказывается купцом и дарит специи (2 шт.).

### 6. Арабская лига — «Засуха»

Событие: колодцы пересохли, запасы тают (стандартное событие «Засуха»).

Стандартные варианты:
1. Урезать рацион
2. Искать воду
3. Довериться проводнику [спутник: проводник]

**Новый вариант (карма > +30 с Арабской лигой):**
4. *«Воспользоваться секретным колодцем»* — арабские торговцы поделились картой тайных колодцев пустыни. Результат: еда +10, опасность −5. Никаких негативных последствий.

### 7. Средиземноморская лига — «Контрабандисты»

Событие: скрытные фигуры предлагают экзотику (стандартное событие «Контрабандисты»).

Стандартные варианты:
1. Торговать
2. Уйти
3. Крупная сделка [деньги >= 35]

**Новый вариант (карма > +30 со Средиземноморской лигой):**
4. *«Предъявить знак Лиги»* — контрабандисты оказываются людьми Лиги, работающими под прикрытием. Предлагают эксклюзивный товар по себестоимости. Результат: покупка до 3 единиц любого товара со скидкой 40%, навык(торговля +10).

## Взаимодействие с эпохами

Мир SilkPathJourney охватывает несколько исторических эпох. Баланс сил между гильдиями меняется в зависимости от текущей эпохи.

### Эпоха 1. Ханьская (~130 г. до н.э. — 220 г. н.э.)

Открытие Шёлкового пути. Китай доминирует.

| Гильдия | Сила | Изменения |
|---------|------|-----------|
| Ханьские торговцы | Максимальная | +10% к продажным ценам китайских товаров, −20% пошлины в Китае |
| Тибетское братство | Слабая | Только Лхаса и Лицзян активны. Хотан и Дуньхуан ещё не в сети |
| Согдийский союз | Растущая | Караванные остановки только формируются. Бонусы посредничества −50% |
| Персидский караван | Сильная | Парфянская империя контролирует торговлю. Стандартные бонусы |
| Индийское сообщество | Сильная | Кушанская империя. Буддийские торговые связи крепки |
| Арабская лига | Слабая | Доисламская Аравия. Только Мекка и Медина (торговля ладаном) |
| Средиземноморская лига | Сильная | Римская империя. Высокий спрос на шёлк в Константинополе |

### Эпоха 2. Танская (618 — 907 гг.)

Золотой век Шёлкового пути. Максимальная торговля.

| Гильдия | Сила | Изменения |
|---------|------|-----------|
| Ханьские торговцы | Сильная | Империя Тан открыта для торговли. Все города активны |
| Тибетское братство | Максимальная | Тибетская империя. Все 4 города активны, военная сила |
| Согдийский союз | Максимальная | Пик согдийской торговли. Все бонусы на максимуме |
| Персидский караван | Сильная | Сасаниды, затем ислам. Перестройка, но торговля крепнет |
| Индийское сообщество | Сильная | Стабильная торговля. Стандартные бонусы |
| Арабская лига | Растущая | Халифат расширяется. Все 5 городов активны, растут бонусы |
| Средиземноморская лига | Сильная | Византия на пике. Стандартные бонусы |

### Эпоха 3. Монгольская (1206 — 1368 гг.)

Pax Mongolica. Безопасность дорог, но разрушение городов.

| Гильдия | Сила | Изменения |
|---------|------|-----------|
| Ханьские торговцы | Ослабленная | Монгольское завоевание. +25% цены в Китае, но −30% опасность на дорогах |
| Тибетское братство | Ослабленная | Под монгольским влиянием. Ограниченная автономия |
| Согдийский союз | Сильная | Монголы ценят торговцев. Яса (монгольский закон) защищает караваны |
| Персидский караван | Ослабленная | Разорение от завоевания, но затем восстановление через Ильханат |
| Индийское сообщество | Сильная | Делийский султанат. Независимость от монголов |
| Арабская лига | Максимальная | Мамлюки в Египте. Контроль торговли Красного моря |
| Средиземноморская лига | Максимальная | Крестовые походы и итальянские республики. Расцвет левантийской торговли |

### Эпоха 4. Смутная (1368 — 1500 гг.)

Упадок Шёлкового пути. Морские маршруты становятся важнее.

| Гильдия | Сила | Изменения |
|---------|------|-----------|
| Ханьские торговцы | Ослабленная | Мин закрывают торговлю. −30% ассортимент, +20% пошлины |
| Тибетское братство | Стабильная | Изоляция защищает от хаоса. Стандартные бонусы |
| Согдийский союз | Ослабленная | Тимуриды разрушают торговые сети. −50% бонусы посредничества |
| Персидский караван | Стабильная | Тимуриды, затем Сефевиды. Перестройка торговли |
| Индийское сообщество | Максимальная | Расцвет морской торговли. Все бонусы на максимуме |
| Арабская лига | Сильная | Контроль морских путей. Высокие доходы |
| Средиземноморская лига | Ослабленная | Падение Константинополя (1453). Потеря штаб-квартиры, −20% цены |

### Влияние на геймплей

Эпоха определяет стартовые условия забега и влияет на:
- Начальный множитель силы каждой гильдии
- Доступность городов (некоторые могут быть разрушены или недоступны)
- Ценовые модификаторы в регионах
- Доступность квестовых веток (ослабленная гильдия имеет укороченные квесты)
- Частоту и тип событий на дорогах

## Расширенные городские модификаторы

Модификаторы (смотри Города) взаимодействуют с гильдейской системой. Когда на город действует модификатор, гильдия, контролирующая этот город, реагирует.

### Война

| Эффект | Значение |
|--------|----------|
| Карма с гильдией города | −3 для всех игроков при посещении |
| Обоснование | Гильдия занята обороной, не может обслуживать торговцев как обычно |
| Здания гильдии | Гильдия работает с ограничениями (только приём заданий, без торговых бонусов) |
| Побочные задания | Недоступны (гильдия не принимает заказы) |

## Структура данных

```
GuildData:
  id: string                     // "han_merchants", "tibetan_brotherhood" и т.д.
  name: LocalizedString
  nativeName: string             // Название на родном языке ("漢商", "བོད་ཚོང" и т.д.)
  description: LocalizedString
  icon: Sprite
  values: LocalizedString[]      // Список ценностей
  specialization: ItemType[]     // Типы товаров специализации
  cities: CityId[]               // Города гильдии
  headquartersCity: CityId       // Штаб-квартира
  allyGuilds: GuildId[]          // Союзные гильдии (из матрицы отношений)
  rivalGuilds: GuildId[]         // Соперничающие гильдии

GuildKarmaData:
  guildId: GuildId
  value: int                     // Текущая карма (-100..+100)
  level: GuildKarmaLevel         // Текущий уровень отношений

GuildKarmaLevel:
  - Enemy          // Враг (-100..-51)
  - Distrust       // Недоверие (-50..-21)
  - Neutral        // Нейтральный (-20..+20)
  - Trust          // Доверие (+21..+50)
  - Ally           // Союзник (+51..+100)

GuildRelationType:
  - Alliance       // Союз (+)
  - Neutral        // Нейтралитет (0)
  - Rivalry         // Соперничество (-)

GuildRelation:
  guildA: GuildId
  guildB: GuildId
  type: GuildRelationType

PlayerGuildState:
  guildKarma: GuildKarmaData[7]        // Карма с каждой гильдией
  activeGuildQuests: GuildQuestData[]   // Активные квесты гильдий
  completedGuildQuests: string[]        // Завершённые квесты (по ID)

GuildQuestData:
  guildId: GuildId
  questStage: int              // Текущий этап (1-5)
  questId: string              // ID задания
  isActive: bool
```

```

  - MaxGuildKarma              // Карма с гильдией <= value (target: ID гильдии)
  - GuildLevel                 // Уровень отношений (target: ID гильдии, value: уровень)
  - InGuildCity                // В городе гильдии (target: ID гильдии)
```
