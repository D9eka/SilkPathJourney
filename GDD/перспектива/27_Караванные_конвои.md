# Караванные конвои

> **Перспективный дизайн.** Этот документ описывает систему караванных конвоев, которая НЕ запланирована к немедленной реализации. Конвои добавляют ощущение живого мира и стратегический выбор между безопасностью и свободой. Документ создан для фиксации идей и обеспечения совместимости с текущей архитектурой.

## Обзор

NPC-караваны регулярно путешествуют между городами по фиксированным маршрутам. Игрок может присоединиться к попутному конвою, чтобы путешествовать безопаснее, но теряет контроль над скоростью и маршрутом.

Конвои решают две проблемы:
- **Ощущение живого мира:** игрок не единственный торговец на Шёлковом пути
- **Стратегический выбор:** безопасность vs свобода, экономия vs конкуренция

## Типы конвоев

### Три типа

| Тип | Скорость | Опасность | Плата | Доступность |
|-----|----------|-----------|-------|-------------|
| Торговый | 25 км/день (медленный) | −50% | 10% от стоимости груза | Всегда |
| Военный | 35 км/день (быстрый) | −70% | 30 монет + пропуск* | Репутация ≥ 50 |
| Паломнический | 20 км/день (очень медленный) | −30% | Бесплатно (пожертвование) | Всегда |

*Пропуск = документ, покупаемый в казармах столицы (10 монет). Действует один рейс.

### Торговый конвой

Группа из 5-15 караванов NPC, объединившихся для безопасности. Самый распространённый тип.

**Маршруты:** Любые основные маршруты между крупными городами (торговые узлы, столицы, порты).

**Особенности:**
- Медленная скорость — конвой движется со скоростью самого медленного участника
- Регулярное расписание: отправка каждые 5-10 дней из крупных городов
- Возможность торговли с другими караванщиками прямо на маршруте (цены хуже городских на 15%)
- Общие припасы: расход снижается на 20% (экономия масштаба)

**Ограничение:** Другие торговцы в конвое везут те же товары → при прибытии в город цены на товары конвоя падают на 10% (перенасыщение рынка).

### Военный конвой

Вооружённый отряд, сопровождающий государственный или дипломатический груз. Быстрый и безопасный, но требует допуска.

**Маршруты:** Стратегические направления (Чанъань→Кашгар, Самарканд→Багдад, Дамаск→Константинополь).

**Особенности:**
- Очень высокая безопасность (−70% опасность)
- Быстрая скорость (35 км/день — не зависит от телеги игрока)
- Нельзя останавливаться на привал (конвой не ждёт)
- Нельзя менять режим движения
- При обнаружении контрабанды — немедленное исключение + штраф

**Требования:**
- Репутация ≥ 50
- Военный пропуск (покупается в казармах)
- Отсутствие контрабанды

### Паломнический конвой

Группа паломников, идущая к святому городу. Бесплатно, но очень медленно.

**Маршруты:** К святым городам (Мекка, Медина, Лхаса, Дуньхуан).

**Особенности:**
- Бесплатное присоединение (по желанию — пожертвование, +5 репутация)
- Очень медленная скорость (паломники идут пешком)
- +10 мораль за каждые 5 дней в конвое (духовный подъём)
- Умеренная безопасность (−30%) — паломников грабят реже, но они беззащитны
- Целитель-паломник может вылечить болезнь бесплатно (шанс 30%)

## Расписание конвоев

### Генерация

Конвои генерируются для каждого крупного города (торговые узлы, столицы, порты) на старте забега:

```
интервал = базовый_интервал + случайное_смещение
```

| Тип города | Базовый интервал | Смещение |
|------------|------------------|----------|
| Столица | 5 дней | ±2 |
| Торговый узел | 7 дней | ±3 |
| Порт | 8 дней | ±3 |
| Остальные | Конвои не формируются | — |

Конвой формируется в городе и отправляется в случайный соседний крупный город (через 1-2 промежуточных). Маршрут конвоя фиксирован на момент создания.

### Видимость на карте

Игрок видит конвои на стратегической карте:

| Элемент | Как отображается |
|---------|------------------|
| Конвой в городе | Иконка каравана рядом с городом + надпись «Конвой → [Город] через 2 дня» |
| Конвой в пути | Движущийся маркер на маршруте (отличается от игрока цветом) |
| Расписание | В таверне можно узнать, когда следующий конвой |

### Информация в таверне

При посещении таверны (или у проводника-спутника) игрок узнаёт:

```
┌──────────────────────────────────────────┐
│  Ближайшие конвои из Самарканда:         │
│                                          │
│  🐪 Торговый → Бухара      через 3 дня  │
│  ⚔️ Военный → Кашгар       через 7 дней │
│  🕌 Паломнический → Мекка  через 12 дней │
└──────────────────────────────────────────┘
```

## Присоединение к конвою

### Как присоединиться

1. Находясь в городе, где формируется конвой, открыть экран конвоев (через таверну или караван-сарай)
2. Выбрать конвой из списка доступных
3. Оплатить (если требуется)
4. Караван игрока автоматически отправляется с конвоем

### Условия

| Условие | Торговый | Военный | Паломнический |
|---------|----------|---------|---------------|
| Репутация | Любая | ≥ 50 | Любая |
| Плата | 10% от стоимости груза | 30 монет + пропуск | Бесплатно |
| Контрабанда | Разрешена (риск) | Запрещена | Разрешена |
| Макс. телег | Без ограничений | 2 телеги | 1 телега |

### Выход из конвоя

Игрок может покинуть конвой в любом промежуточном городе:

- Конвой останавливается в каждом городе на маршруте на 1 день
- Игрок может выйти без штрафа
- Плата не возвращается
- Продолжить путь самостоятельно

Покинуть конвой между городами нельзя (конвой не останавливается в пустыне).

## Бонусы путешествия в конвое

### Снижение опасности

Основной бонус. Формула:

```
итоговая_опасность = базовая_опасность × (1 − бонус_конвоя)
```

| Тип конвоя | Бонус |
|------------|-------|
| Торговый | 0.50 (−50%) |
| Военный | 0.70 (−70%) |
| Паломнический | 0.30 (−30%) |

### Экономия на припасах

Общие костры, общая охрана, общие колодцы:

```
расход_припасов = базовый_расход × (1 − экономия_конвоя)
```

| Тип конвоя | Экономия |
|------------|----------|
| Торговый | 20% |
| Военный | 10% (военные не делятся) |
| Паломнический | 25% (паломники щедры) |

### Социальные события

В конвое доступны уникальные события:

| ID | Название | Описание |
|----|----------|----------|
| convoy_trade | Торговля в пути | Другой караванщик предлагает обмен товарами (цены ±15% от рыночных) |
| convoy_rumor | Караванные слухи | Узнаёшь информацию о ценах или опасностях по маршруту |
| convoy_companion | Новый знакомый | Возможность нанять спутника из конвоя (без города) |
| convoy_dispute | Спор о маршруте | Конвой хочет сменить маршрут. Харизма → убедить остаться на прежнем |
| convoy_theft | Кража в конвое | У игрока пропал товар. Расследование (Харизма) или потеря |
| convoy_celebration | Привал с песнями | +5 мораль, −2 припаса (угощение) |

Шанс социального события = 15% за день в конвое.

## Ограничения и риски

### Потеря контроля

| Ограничение | Описание |
|-------------|----------|
| Скорость фиксирована | Нельзя переключить режим «Гоним» |
| Маршрут фиксирован | Конвой идёт своим путём, отклониться нельзя |
| Привал по расписанию | Конвой привал делает каждые 3 дня, игрок не выбирает когда |
| Действие на привале | Доступно только 1 действие (как обычно), но действие определяется голосованием конвоя (60% шанс совпадения с желанием игрока) |

### Конкуренция

При прибытии в город вместе с торговым конвоем рынок перенасыщается:

```
цена_продажи = базовая_цена × sell_coef × (1 − перенасыщение)
```

| Размер конвоя | Перенасыщение |
|---------------|---------------|
| Малый (5-8 караванов) | 10% |
| Средний (9-12 караванов) | 15% |
| Крупный (13-15 караванов) | 20% |

Перенасыщение действует 3 дня после прибытия конвоя.

### Репутационные последствия

| Действие | Эффект |
|----------|--------|
| Присоединиться к конвою | +2 репутация (доверие) |
| Покинуть конвой в городе | Без последствий |
| Обворовать кого-то в конвое | −15 репутация, исключение из конвоя |
| Защитить конвой от нападения | +10 репутация |

## Взаимодействие с NPC-караванами

### Встреча на дороге

Даже без присоединения к конвою игрок может встретить NPC-караваны на маршрутах. Это обычные события:

| Событие | Описание |
|---------|----------|
| Встречный караван | Обмен новостями (раскрывает эффект на дороге) |
| Попутный караван | Предложение присоединиться (если совпадает направление) |
| Разгромленный караван | Следы нападения. Подобрать товары (−репутация) или помочь раненым (+репутация) |
| Конкурент | NPC-торговец едет к тому же городу. Кто прибудет первым — тот продаст выгоднее |

### Информация от проводника

Спутник-проводник (смотри Спутники) знает расписание конвоев:

| Уровень проводника | Информация |
|---------------------|-----------|
| Новичок | Знает, из каких городов отправляются конвои |
| Опытный | Знает расписание ближайшего конвоя (город + день) |
| Мастер | Знает расписание всех конвоев на 30 дней вперёд |

## Структура данных

### ConvoyType (enum)

```
ConvoyType:
  Trade = 0        // Торговый
  Military = 1     // Военный
  Pilgrimage = 2   // Паломнический
```

### ConvoyConfig (ScriptableObject)

```
ConvoyConfig:
  convoyType: ConvoyType
  displayName: LocalizedString
  speed: float                     // 25, 35, 20 км/день
  dangerReduction: float           // 0.50, 0.70, 0.30
  supplyEconomy: float             // 0.20, 0.10, 0.25
  cost: ConvoyCost                 // Стоимость присоединения
  requiredReputation: int          // 0, 50, 0
  maxCarts: int                    // 0 (без лимита), 2, 1
  allowContraband: bool            // true, false, true
  marketSaturation: float          // 0.10-0.20 (только для торговых)
  moralePerFiveDays: int           // 0, 0, 10 (только для паломнических)
  restInterval: int                // 3 (привал каждые N дней)
```

### ConvoyCost

```
ConvoyCost:
  type: CostType                   // Percentage, Fixed, Free
  percentage: float                // 0.10 (10% от стоимости груза)
  fixedAmount: int                 // 30 (монет)
  requiresPass: bool               // false, true, false
```

### ConvoyInstance (рантайм)

```
ConvoyInstance:
  id: string                       // Уникальный ID конвоя
  config: ConvoyConfig
  originCity: CityId               // Откуда
  destinationCity: CityId          // Куда
  route: CityId[]                  // Полный маршрут (с промежуточными)
  departureDay: int                // День отправки
  currentSegment: int              // Текущий сегмент пути
  size: int                        // 5-15 (количество NPC-караванов)
  hasPlayer: bool                  // Игрок присоединился?
```

### ConvoySchedule (ScriptableObject)

```
ConvoySchedule:
  city: CityId
  baseInterval: int                // 5, 7, 8 (дней)
  intervalVariance: int            // ±2, ±3
  convoyTypes: ConvoyType[]        // Какие типы формируются в этом городе
  destinations: CityId[]           // Возможные направления
```

### Приоритет реализации

1. Генерация расписания конвоев для крупных городов
2. Отображение конвоев на карте (маркеры)
3. Механика присоединения/выхода
4. Бонусы безопасности и экономии
5. Социальные события в конвое (6 штук)
6. Перенасыщение рынка
7. Информация от проводника
8. Встречи с NPC-караванами на дорогах
